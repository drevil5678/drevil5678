選手無法連線時，依序檢查
  1. 主辦程式視窗保持開啟，主機連到場地有線網路或 Wi-Fi。
  2. 選手電腦連到相同區域網路，輸入上方完整網址。
  3. Windows 防火牆允許本程式使用私人網路。
  4. 檢查 Wi-Fi 是否啟用訪客隔離；先用一台選手電腦測試。
  5. 主機更換網路或 IP 後，按「重新檢查」並重新分享網址；可向場地管理員預留固定 IP。

EVENT OPERATIONS

上場前，先確認。

選手

  1. 找到自己的對戰桌，輸入主辦方發給點棋手的操作碼。
  2. 開賽前決定是否參考自備設備。使用者僅有 5 分鐘，其他為 10 分鐘。
  3. 紅色叉號是 AI 最高勝率落點，禁止落子；綠色數字是其他 AI 建議。也可選擇未標記的合法落點。
  4. 點選棋盤後，按「確認落子」。關閉或重新整理瀏覽器不會停止計時。
  5. 分析等待不扣選手時間；伺服器收到合法落子後切換對方並分析。
  6. 从第 61 手開始，最佳合法可選點勝率連續三個自身回合 ≤ 40.00% 判負。介面顯示四位小數供核對，判定使用原始值。

裁判與主辦方

  1. 先確認規則、模型與現場效能，再檢錄隊伍並建立首輪。
  2. 每桌開賽前檢查雙方自備設備選項，個別按「開賽」。
  3. 因主辦方系統或網路異常，可填寫原因並暫停、恢復或重賽。
  4. 雙方停一手會暫停，需由裁判依公告規則裁定勝隊及積分。
  5. 用時耗盡勝方得 1 分；連續低勝率判負勝方得 1.25 分；敗方 0 分。
  6. 每輪備份資料庫並匯出紀錄。若伺服器重啟，逐桌確認後恢復。

50 台電腦的配置

32 台供各隊指定點棋手；其餘可供隊員共同討論、裁判、排行榜、備用席。最多 16 場同時對弈。所有電腦以瀏覽器連到同一台區域網路伺服器，AI 不需要安裝在每台選手電腦。

正式活動需另確認 GPU 主機、有線網路、電源與斷線處置。目前附帶 CPU 小模型供開發驗證，尚未證明現場效能。
