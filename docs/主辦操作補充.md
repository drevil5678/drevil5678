# 主辦與裁判操作（v0.6.0）

此文件供主辦使用；公開「參賽說明」僅保留選手操作。

## 名單與碼卡

18 隊正式名單與主辦指定的固定碼已內建。全隊預設完成資格確認及檢錄，無需火星積分，「暫無」是有效隊員姓名。空白賽事自動預載；既有棋局保留。初次升級完全符合內建名單的隊伍會一次更新為固定碼，詳見 [18 隊快速開賽](18隊快速開賽.md)。

使用管理頁「賽前列印隊伍點棋碼」，或直接開啟套件根目錄 `TEAM-CODES.html` 列印（亦有 `TEAM-CODES.csv`）。同隊跨輪沿用，輸入碼會辨識目前所屬隊伍。需要換碼時可「重新制發」並填寫原因；舊固定碼及該隊舊局操作碼立即失效。管理金鑰與隊伍碼不同，仍由本機 `data/admin-token` 產生。

## 每輪開始

1. 核對並儲存規則後建立瑞士賽。每輪結果全部完成，才能建立下一輪，共五輪。
2. 按一鍵開始本輪全部桌，不需逐桌操作。這是開放開賽；未完成猜先與準備的桌不會開始計時。
3. 雙方各擲兩顆骰子，在棋盤中央看完動畫後按「確定」確認，再由總和高者選黑／白；平手會重新擲骰，雙方與觀戰者都能看見點數。選色後雙方按「準備好了」，才分析首手及啟動計時。
4. 如需自備電子產品扣時，請選手在準備完成前設定。一般局 10／5 分鐘；冠軍戰每局 15／10 分鐘。
5. 每輪核對成績並備份。五輪後建立八強，淘汰賽對決圖會依已產生賽程及結果填入，未定席位留空。

裁定結果只需選勝隊及 1／1.25 分，**不需填理由**。暫停、重賽仍保留原因與紀錄；已完成棋局不覆寫。重賽保存原 SGF、時間及事件後，重新猜先準備。

## 特別對戰桌

在後台指定兩支不同隊伍建立特別桌，用於臨時獨立對決。仍有點棋碼權限、骰子猜先、選色、準備、時計與棋譜。結果可在隊伍紀錄查看，**不計瑞士積分、對手積分或淘汰晉級**；正式輪次不必等待特別桌結束。

## 雙方虛手與計分

連續雙方虛手後立即依棋盤現況計分，不移除死子、不要求雙方確認。中國規則算盤上棋子與單方包圍空點；日本規則算空與提子。白方加入設定貼目，勝方得 1 分、敗方 0 分。若設定導致完全同分，系統暫停，請裁判裁定。第 61 手起連續低勝率判負仍為勝方 1.25 分；超時為 1 分。

## 同一網站的練習

選手從主網站「練習」進入，與賽場使用相同網址及連接埠。僅同機雙人或人對電腦，不能從其他電腦加入對局；每個瀏覽器只保留一桌，不計正式賽分。每桌綁定開桌的瀏覽器與裝置，重整可繼續；先下載 SGF 再收桌。

只需啟動 Start-LAN；Start-Practice／Start-Practice-LAN 亦開啟相同主網站。練習與正式比賽共用主機 AI，正式賽前須測量同時負載；效能依硬體而定。收桌、閒置回收或重啟會清除練習棋局。

## 紀錄與備份

公開隊伍紀錄列出目前、歷史與已排定棋局，不猜測瑞士下一輪對手。SGF 可下載。管理頁手動備份、每 10 分鐘自動備份、啟動前 WAL 完整備份皆保留；每輪將 `data/backups/` 的完成備份複製至備用主機或 USB。

JSON 匯出不含隊伍碼，完整 SQLite 備份則包含。停止服務後才進行資料還原，避免兩個程序同時操作同一資料庫。
