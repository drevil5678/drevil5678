# 主辦與裁判操作補充（v0.4.0）

18 隊名單已依主辦要求內建，空白賽事首次啟動會自動建立，不需貼表格。實際點棋碼在本機產生，既有隊伍及碼表沿用，不隨公開套件發布；詳見 [18 隊快速開賽](18隊快速開賽.md)。

此文件供主辦方使用，公開網頁的「參賽說明」只保留選手需要的操作與規則。

## 預先制發隊伍點棋碼

1. 登入主辦管理，建立或 CSV 匯入報名隊伍。
2. 報名時即產生每隊固定點棋碼，不需先檢錄或建立首輪。
3. 按 **賽前列印隊伍點棋碼**，按隊伍分開制發。也可在名單按「查看點棋碼」。
4. 同隊整場沿用，每輪自動辨識該隊棋色。隊名或隊員調整不會自動改碼。
5. 遺失或需換碼時按「重新制發」，填寫原因；原固定碼及該隊舊版的各局操作碼立即失效，不改動棋盤、時鐘或成績。

v0.2.0 資料升級時，系統會為已有隊伍加入固定碼，保留既有比賽、成績與舊版操作碼的相容性。正常重新啟動不改碼。未重新制發前，已發出的舊版各局碼仍可用於原棋局。

管理頁與完整資料庫備份含點棋碼，請保管。公開賽場、隊伍紀錄及賽務 JSON 匯出不含點棋碼。列印參賽網址時不會同時印出私密操作碼。

## 隊伍對戰紀錄

選手可從「隊伍紀錄」或積分榜的隊名進入，看到目前對戰、已排定賽程及所有已完成棋局。配對與結果更新會同步顯示，已完成棋局可查看或下載 SGF。

瑞士制下一輪必須待本輪全部完成，再由主辦方建立。系統不顯示猜測的下一輪對手；六輪後按成績決定八強。淘汰隊伍會顯示賽程結束，冠軍戰依三戰兩勝決定是否續局。

## 區網自由練習：最多 15 桌

Windows 雙擊 **Start-Practice.cmd** 或 **Start-Practice-LAN.cmd**；Linux 執行 `./YanghaiTournament --practice-lan`。預設監聽區網連接埠 8001，玩家開啟練習網址後，自行選擇真人、電腦或同機雙人模式開桌。詳見 [區網練習大廳](區網練習大廳.md)。

KataGo 與模型在本機計算，不需 Internet。練習使用獨立的 practice-data 目錄作為程序鎖與 AI 日誌位置，不開啟正式賽資料庫，不建立管理金鑰，不加入排名或裁判紀錄。正式服務與練習服務有不同連接埠和程序鎖。

三種模式合計最多 15 桌，包含等待、對弈、分析及已結束未收桌的棋局；第 16 桌會被拒絕。開桌者收桌後釋放名額，30 分鐘無落子或操作會自動回收。真人玩家各持自己的操作碼與棋色；悔棋需對手同意。電腦會自動落子，悔棋退回最近的玩家回合。無計時、正式積分或 40% 連續判負。棋局只留在記憶體，請先下載 SGF；收桌、逾時或重開程式會清除。

原有離線同機雙人用 **Start-Practice-Offline.cmd** 或 `--practice` 啟動，只允許本機連線。

請把區網練習放在另一台備用電腦，避免佔用正式 AI 主機的運算資源。電腦分析在背景排隊；15 桌是名額上限，實際延遲須以現場硬體彩排。隨附 AVX2 CPU 小模型仍為開發／預演用途。

## 勝率與貼目

正式及練習每次 KataGo 分析請求都包含設定的 `komi`。黑貼 7.5 目以 `komi: 7.5` 傳入，作為白方補償，勝率已由 KataGo 計入，不另在百分比上加減 7.5。

`reportAnalysisWinratesAs = SIDETOMOVE` 固定以輪到行棋方顯示勝率；中國規則使用 chinese-ogs 以匹配位置超劫。40.00% 是主辦指定的判負門檻，與貼目是不同設定。估計勝率受模型及分析預算影響，正式使用需固定版本與 visits。
