# 四強賽單機版（Windows 10／11 x64）

下載 **yanghai-windows-final-four-port8001**，完整解壓附件與其中的 ZIP，保留整個資料夾。雙擊 **Start-FinalFour-8001.cmd**，會啟動 **YanghaiFinalFour.exe** 並開啟瀏覽器。不需安裝 Python，也不需網路、管理金鑰或點棋碼。隨附 CPU KataGo，需支援 AVX2 的 x64 CPU。

網址固定為同一台電腦的 `http://127.0.0.1:8001`。CMD 明確指定 `--port 8001`，首次產生的 **final-four.json** 也使用 8001。本版兩隊共用一台電腦，一次進行一局。

1. 填入四個不同隊名，按「建立四強對決圖」。第 1 隊對第 2 隊，第 3 隊對第 4 隊。
2. 在賽場選擇四強組別，勾選該隊是否攜帶電子產品，按「開啟第 1 局」。雙方各擲兩顆骰子並確認，由較高者選黑白，再各按準備。
3. **四強一戰決勝**，兩場勝隊自動進入冠軍戰。四強結束後不能再開第二局。
4. **冠軍戰三戰兩勝**，每局重新擲骰。先贏兩局即為冠軍；2：0 結束，1：1 時開第三局。每局勝利只算一勝，40% 判負的 1.25 分也只算一勝。

所有階段每局每隊 **10 分鐘**，攜帶電子產品者 **5 分鐘**。共用的比賽電腦不算額外自備設備。AI 分析與排隊時暫停計時。

沿用 19 路、黑貼 7.5 目、中國規則與 128 visits。禁止 AI 最佳落點；從第 61 手起，連續三個自身回合的最佳合法可選點勝率 ≤ 40% 判負。雙方連續虛手後依棋盤現況與貼目計分，不另外移除死子。主辦可暫停、恢復或裁定單局勝隊；平手由主辦裁定，不自動算任何一方一勝。

資料存於獨立的 **final-four-data/**，不讀取舊版 `knockout-data/`、正式賽 `data/` 或雙隊版 `duel-data/`。重啟保留四隊名單、對決圖、勝局與棋盤；未完成的對弈以暫停狀態恢復。請保留整個資料夾；另一屆賽事可解壓到新的資料夾開始。

每局可下載 SGF，也可下載整屆 JSON 紀錄。建議活動前先用實際電腦完整試打一場；隨附模型適合開發與預演，其正式比賽棋力仍需主辦評估。
