# 本地免安裝版（v0.8.1）

一台主機執行程式，選手用同一區網的瀏覽器加入。主機不用安裝 Python／Node／uv；選手不用安裝軟體。套件包含執行檔、前端、KataGo、模型與設定，須完整解壓。

## 取得與啟動

依 [GitHub 下載說明](GitHub下載Windows測試版.md) 取得 `yanghai-windows-lan-v0.8.1`。不要在 ZIP 預覽裡啟動或只複製 exe；解壓至可寫入資料夾，雙擊 **Start-LAN.cmd**。程式建立 `tournament.json`、`data/` 並開啟主辦管理頁，用 `data/admin-token` 登入。

18 隊已內建、預設完成檢錄，固定碼隨根目錄 `TEAM-CODES.html`／`TEAM-CODES.csv` 提供，HTML 可直接開啟列印，也可從管理頁印碼卡。賽場、排行榜、隊伍紀錄、淘汰賽、單機練習同埠啟動。`Start-Practice.cmd` 與 `Start-Practice-LAN.cmd` 是相同主網站入口；舊本機雙人可用 Start-Practice-Offline。

程式視窗需保持開啟；Ctrl+C 正常停止。先核對 `.sha256`，不要放唯讀 Program Files、網路共享碟或同步中的資料夾。Windows 版需 x64 與 AVX2 相容 CPU。

## 更新與資料

保留現場 **tournament.json 與整個 data/**，更換程式及其配套檔案。18 隊與碼表升級政策見 [18 隊快速開賽](18隊快速開賽.md)。既有棋局、成績與備份不清除。

- 每個資料目錄只允許一個程序；重複啟動不會覆寫資料。連接埠衝突會先停止，不關閉其他程式。
- 啟動既有資料庫前先以 SQLite 備份 API 保存 WAL 完整快照，每 10 分鐘自動備份；管理頁可手動備份。
- 重啟保留正式棋局並暫停，裁判核對後恢復。練習只存在記憶體，請先下載 SGF。
- 每輪將 `data/backups/` 的完成備份複製至備用主機／USB。不要在執行中只複製 tournament.sqlite3 而忽略 WAL。
- 不要讓舊 Python 服務與執行檔同時指向同一資料庫，不要使用多個 Uvicorn worker。

## 設定與建置

`tournament.json` 路徑相對於設定檔所在資料夾：

```json
{
  "host": "0.0.0.0",
  "port": 8000,
  "data_dir": "data",
  "katago_bin": "katago/katago.exe",
  "katago_model": "model/model.txt.gz",
  "katago_config": "config/analysis.cfg",
  "ai_concurrency": 1,
  "auto_backup_seconds": 600,
  "open_browser": true,
  "engine_mode": "auto",
  "katago_gpu_bin": "katago-gpu/katago.exe",
  "katago_gpu_config": "config/analysis-gpu.cfg",
  "gpu_concurrency": 4,
  "gpu_device": -1
}
```

`--lan` 本次監聽區網，`--port` 改本次連接埠，`--no-browser` 停用自動開頁，`--config` 選設定檔，`--check` 做真實 AI 載入診斷。相容的 `--practice-lan` 現在啟動主網站；`--practice` 保留舊本機雙人模式。

Windows exe 在 Windows x64 建置：`uv sync --locked --group build`，接著 `scripts/build-windows.cmd`。Linux 用 `.venv/bin/python scripts/build_portable.py --output dist/yanghai-linux-x64-new`；Linux binary 不能當 Windows exe。

KataGo v1.16.3 CPU、GPU 引擎與模型下載均有摘要驗證。Windows 可使用隨附 OpenCL GPU 引擎，先讀 [GPU 與 12 桌測速](GPU與12桌測速.md)。預設 b6c96／128 visits 僅供預演。正式 GPU binary、模型與 visits 可透過 KATAGO_BIN／KATAGO_MODEL／KATAGO_CONFIG 及 AI_CONCURRENCY 設定，保持 reportAnalysisWinratesAs = SIDETOMOVE。正式硬體與 50 台實際場地電腦須另行彩排，包含 9 桌正式賽及練習的同時負載。
