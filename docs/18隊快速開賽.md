# 18 隊快速開賽（v0.7.1）

1. 完整解壓 Windows 套件，雙擊 **Start-LAN.cmd**。用本機 `data/admin-token` 登入主辦管理頁。
2. 空白賽事自動建立主辦提供的 18 隊、隊長、隊員與報名順位。全部預設完成資格確認及檢錄，無需火星積分；吳暫聯隊的隊員姓名「暫無」有效。
3. 固定點棋碼已按主辦要求寫入程式，套件根目錄 `TEAM-CODES.html` 可直接開啟列印，`TEAM-CODES.csv` 可供編輯；也可按「賽前列印隊伍點棋碼」印碼卡。同隊跨輪沿用。
4. 升級既有資料時，18 隊中隊名、兩名隊員完全相符者，會一次套用新版固定碼；其他隊伍也預設完成檢錄。此後重新啟動保留碼；若主辦手動重新制發，不會在下次啟動改回。請以管理頁顯示與列印為準。
5. 確認正式規則並儲存。按「建立下一輪瑞士賽」產生 9 桌，再按一鍵開始本輪；雙方完成骰子猜先、選色與準備後實際開局。
6. 本輪全部結束後核對結果、備份，再建立下一輪。共 **五輪**，完成後取前八名淘汰賽。

之後只需雙擊 Start-LAN，保留 `tournament.json` 和整個 `data/`。已存在隊伍、輪次或棋局時，不追加 18 隊或清除比賽。另開測試賽事請用新資料夾，不要刪除實際資料。

## 瑞士配對

第一輪依最終報名順位配 1–2、3–4，直到 17–18。第二輪起，依「積分 → 對手積分總和 → 報名順位」排序。從最高排名尚未配對的隊伍開始，向下依排名找最近的未交手隊伍；若剩餘隊伍無法完成配對，回退調整前面的選擇。搜尋上限內無完整配對就報錯，不安排重複對手。

配對順序決定對手，黑白由每局骰子猜先決定。下一輪須等本輪結果完成後才能建立，不預先承諾對手。第一輪前更換隊員會依既有政策調整報名順位；「暫無」本身無需修改。
