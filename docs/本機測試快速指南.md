# 本機測試快速指南（v0.8.0）

先在獨立資料夾測試，再部署正式賽事。主機需相容 AVX2 的 Intel／AMD x64 CPU，Windows 10／11；隨附模型供開發與預演。

1. 按 [GitHub 下載說明](GitHub下載Windows測試版.md) 下載並完整解壓，雙擊 **Start-LAN.cmd**。若只測本機，可用 `YanghaiTournament.exe --host 127.0.0.1`。
2. 用記事本讀取本機 `data/admin-token`，登入主辦管理。18 隊預載並完成檢錄，無需輸入資格或火星積分；「暫無」隊員有效。
3. 核對 19 路、黑貼 7.5 目、中國規則、40% 門檻，儲存規則確認。列印固定隊伍碼卡。
4. 建立首輪，按一鍵開始本輪。使用兩個獨立瀏覽器工作階段進同一桌，分別輸入兩隊碼。
5. 雙方擲骰，高點隊選黑白；平手重擲。雙方按「準備好了」，確認才開始時計與 AI 提示。
6. 選手在準備前可選自備電子產品：一般 10／5 分鐘，冠軍戰 15／10 分鐘。
7. 點落點再確認，檢查紅叉禁止、合法點可下、目前手數與下一方更新。主辦暫停／恢復，檢查時間正確。
8. 測試連續虛手自動收官：依盤面現況計分，勝 1、敗 0；可在獨立測試資料用裁定結果直接選勝隊，不需理由。
9. 主辦先於後台「練習開放控制」開啟練習，選手在「練習」輸入隊伍點棋碼登入，再開同機雙人或電腦局；不需第二個連接埠。不能從另一台電腦加入該練習桌；同一瀏覽器只能開一桌。
10. 下載 SGF、備份，Ctrl+C 停止後重開，確認正式名單、碼與棋局保留並暫停；練習棋局清除。

加入第二台電腦時，接同一區網，使用管理頁顯示的主機 IPv4 網址。Windows 防火牆允許活動的私人網路；其他電腦不需安裝。測完請保留彩排資料，正式活動使用獨立資料夾或 `data_dir`。

開發者可在 Windows 安裝 Python 3.12／3.13 與 uv，執行 `uv sync --locked --group build`、`scripts/build-windows.cmd`。Linux 程式必須在 Linux 建置，不能將 Linux binary 改名當 Windows exe；macOS／ARM 未提供免安裝包。
