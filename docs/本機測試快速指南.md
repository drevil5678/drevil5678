# 楊海分站賽：本機測試快速指南

日期：2026-10-10。先用一台電腦、兩支虛構隊伍測試，再加入第二台電腦。隨附 CPU 開發模型不用 NVIDIA 顯示卡，但需要相容 AVX2 的 Intel／AMD x64 CPU。正式比賽的模型與 50 台現場電腦仍需另外彩排。

## Windows 10／11 x64

目前提供原始碼及建置腳本，尚沒有經 Windows 實機驗證的成品 exe。第一次建置需要連網。

1. 下載 `yanghai-source-v0.1.0.zip`，全部解壓縮，找到內含 `pyproject.toml` 的 `yanghai-source` 資料夾。
2. 開啟 PowerShell，安裝 uv：

```powershell
winget install --id astral-sh.uv --exact
```

3. 關閉 PowerShell 再開一次，讓新安裝的命令生效。在 `yanghai-source` 資料夾內開啟終端機，執行：

```powershell
uv python install 3.12
uv sync --locked --group build --python 3.12
.\.venv\Scripts\python.exe scripts\build_portable.py
```

若系統找不到 winget，可依 uv 官方安裝文件 https://docs.astral.sh/uv/getting-started/installation/ 安裝 uv，再接續上述步驟。建置成功前不要把 Windows 版視為已驗證。

4. 成功後，進入 `dist\yanghai-windows-x64`，先做 AI 診斷：

```powershell
.\YanghaiTournament.exe --check
```

看到 `PASS: 真實 KataGo 模型載入與分析成功。` 後，開始單機測試：

```powershell
.\YanghaiTournament.exe --host 127.0.0.1
```

程式自動開啟本機瀏覽器。若沒有自動開啟，在這台電腦的瀏覽器網址列輸入 `http://127.0.0.1:8000`。這是你自己電腦啟動後的服務，雲端並沒有提供可公開連線的預覽網址。請保持程式視窗開啟；停止時按 Ctrl+C。

## Linux x86_64

1. 下載 `yanghai-linux-x64-v0.1.0.zip`，全部解壓缩。進入包含 `YanghaiTournament` 的資料夾。
2. 在終端機執行：

```bash
chmod +x YanghaiTournament katago/AppRun katago/usr/bin/katago
./YanghaiTournament --check
./YanghaiTournament --host 127.0.0.1
```

此版已在 Linux 雲端完成真實 AI 與重新啟動測試，不用另裝 Python 或 Node。確認診斷顯示 PASS，再啟動服務。

macOS 與 ARM 電腦目前沒有相容的免安裝套件。

## 用兩隊完成第一次測試

1. 在程式資料夾以文字編輯器開啟 `data/admin-token`，把內容貼入「主辦管理 → 管理金鑰」後登入。此檔案是本機產生，不在下載的 ZIP 中。不要公開金鑰。
2. 規則先採 19 路、黑貼 7.5 目、中國規則、判負門檻 40%、128 visits，僅在這份測試賽事勾選規則確認後儲存。第一輪建立後規則鎖定。
3. 新增兩支虛構隊伍，每隊兩人，勾選資格確認與已檢錄。
4. 按「建立下一輪瑞士賽」，再按「列印本輪操作碼」取得黑、白方各自的操作碼。
5. 開三個獨立操作視窗，例如 Chrome 一般視窗做主辦、Chrome 無痕視窗做黑方、Edge 做白方。選手視窗從賽場進入同一對戰桌，各自輸入對應操作碼並進入操作席。
6. 開賽前可勾選自備設備並儲存，確認改為 5 分鐘。其餘席位起始為 10 分鐘。由主辦視窗按「開賽」。
7. 交替落子：先點棋盤，再按「確認落子」。確認紅叉首選不能提交，綠色候選或其他合法落點可以提交。
8. 主辦按「暫停」，確認雙方時計停止；按「恢復」，確認可繼續。
9. 按「備份資料庫」。本地執行檔的備份實際位於 `data/backups/`，目前介面提示可能仍寫 `.runtime/backups/`，請以執行檔的資料目錄為準。
10. 在程式視窗按 Ctrl+C，重新啟動。確認棋局、落子和時計保留；既有棋局會保持暫停，經主辦核對後恢復。

測试僅下幾手不會觸發第 61 手起的連續低勝率判負。若要查看積分更新，可在測試資料使用裁判「裁定結果」，輸入明確的示範理由。

## 加入第二台電腦

1. 單機測試通過後，以 Ctrl+C 停止程式，重新啟動，移除 `--host 127.0.0.1`。
2. 第二台電腦與主機連到同一區域網路。Windows 主機用 `ipconfig` 找到目前網卡的 IPv4。
3. 例如主機 IPv4 是 `192.168.1.20`，第二台電腦的瀏覽器輸入 `http://192.168.1.20:8000`，實際位址以你的主機為準。
4. 如 Windows 防火牆詢問，僅允許活動使用的私人區域網路。其他電腦只需瀏覽器，不用安裝 Python、uv 或本程式。

請保留測試資料作為彩排紀錄。正式比賽使用另外一份資料夾或獨立的 `data_dir`，避免示範名單和結果混入正式賽事。
