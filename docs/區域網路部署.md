# 區域網路部署：一台主機，選手使用瀏覽器

適用 Windows 10／11 Intel／AMD x64、相容 AVX2 的主機。程式、KataGo 與模型只放主機，選手不需安裝。

1. 登入 GitHub，開啟 [Windows 建置頁](https://github.com/drevil5678/drevil5678/actions/workflows/windows-build.yml) 的最新成功紀錄，在 Artifacts 下載 `yanghai-windows-lan-v0.7.0`。
2. 解壓附件 ZIP，再完整解壓程式 ZIP，保留 `_internal`、`katago`、`model` 與 `config`。更新請保留原本 `tournament.json` 與 `data/`。
3. 主機與選手接同一有線交換器或場地 Wi-Fi，雙擊 **Start-LAN.cmd**。Windows 防火牆允許活動使用的私人網路。
4. 使用本機 `data/admin-token` 登入主辦管理，在「區域網路開賽」選場地網卡，複製／列印參賽網址。不要選 VPN 或不使用的虛擬網卡。
5. 選手用 Chrome／Edge 開網址，例如 `http://192.168.1.20:8000/#arena`，實際以管理頁顯示為準。`0.0.0.0` 是監聽設定，不能當網址。
6. 保持程式視窗開啟；停止按 Ctrl+C。重啟會保存正式棋局並暫停，裁判核對後恢復；練習棋局會清除。

18 隊預載並完成檢錄，固定碼可由管理頁列印。核對規則、建立第一輪後，按一鍵開始本輪；雙方骰子猜先、選色並準備後才實際對弈。詳見 [18 隊快速開賽](18隊快速開賽.md)。

練習就在同一網站「練習」，使用相同連接埠。只支援同一台選手電腦的人對人／人對電腦，不提供其他裝置加入；每個瀏覽器只保留一桌。

## 連線排查與彩排

- 主機能開而選手不能開：檢查是否同一區網、私人網路防火牆、訪客 Wi-Fi 隔離及選錯網卡。先改接同一交換器測試。
- 主機換網路或 IP 改變，按「重新檢查」並重新分享網址。建議預留固定 IPv4／DHCP 租約。
- 顯示本機模式時，停止後用 Start-LAN 啟動。分享網址不含管理金鑰或點棋碼。
- 先用 1 台、2 台，再用現場 50 台電腦彩排。18 隊正式輪有 9 桌；另測正式 AI 與練習同時負載、時計、斷線、重啟與備份還原。

程式與模型提前備妥後不需 Internet；主機與場地區網仍須正常。隨附小模型的模擬測試不代表現場效能驗收。

命令啟動為 `YanghaiTournament.exe --lan`（Linux 用 `./YanghaiTournament --lan`）。`--port` 可指定本次連接埠；練習隨主網站一起改變，不改寫既有設定。

有 NVIDIA 獨顯時，先執行 `Check-GPU.cmd`，確認主辦後台顯示實際顯卡。開賽前停止伺服器，執行 `Benchmark-12-Tables.cmd` 量測含排隊的等待；需要強制使用 GPU 時，以 `Start-LAN-GPU.cmd` 啟動。詳見 [GPU 與 12 桌測速](GPU與12桌測速.md)。
