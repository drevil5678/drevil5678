# 2026-10-17 楊海分站賽部署（Asia/Taipei）

## 現場架構

一台 Windows／Linux x64 主機執行 FastAPI、SQLite 與 KataGo，所有選手以瀏覽器連同一區網。18 隊正式輪共 9 桌、每隊一個操作席；其餘設備可作裁判、排行榜、同機練習與備用。不要讓 50 台電腦各自安裝 AI。

主機及操作席建議有線 LAN。先準備完整程式與模型，活動不依賴外部 Internet。正式模型、GPU、visits 與同機練習的同時負載，須在現場驗證；開發小模型及模擬客戶端不能替代實機彩排。

Windows 以 Start-LAN.cmd 啟動，依 [區域網路部署](區域網路部署.md) 分享網址。原始碼可用以下設定：

```bash
export KATAGO_BIN=/absolute/path/to/verified/katago
export KATAGO_MODEL=/absolute/path/to/verified/model.bin.gz
export KATAGO_CONFIG=/absolute/path/to/tested/analysis.cfg
export AI_CONCURRENCY=4
HOST=0.0.0.0 PORT=8000 bash scripts/start.sh
```

只使用一個應用程序／Uvicorn worker。引擎須保持 reportAnalysisWinratesAs = SIDETOMOVE；並行數與 KataGo numAnalysisThreads 配合。`/api/health` 的 ai_ready 代表可載入分析，不能代表正式效能已驗收。

## 規則與場次

| 項目 | 設定 |
| --- | --- |
| 名單 | 內建 18 隊，全部預設資格及檢錄完成；「暫無」有效 |
| 預設盤面 | 19 路、黑貼 7.5 目、中國位置超劫；首輪前確認 |
| 瑞士賽 | 五輪，第一輪相鄰報名順位；其後按排行向下找最近未交手隊 |
| 猜先 | 每局兩隊各擲兩骰，比總和；平手重擲，高者選黑白 |
| 開始 | 主辦一鍵啟用本輪，雙方選色並準備後開始 |
| 一般時計 | 每方 10 分鐘，自備電子產品方 5 分鐘 |
| 冠軍時計 | 每局每方 15 分鐘，自備電子產品方 10 分鐘 |
| 低勝率 | 第 61 手起連續三個自身回合最佳可選勝率 ≤ 40%；勝 1.25、敗 0 |
| 超時 | 勝 1、敗 0 |
| 連續雙虛手 | 不移除死子，按當前盤面及規則自動算分；勝 1、敗 0 |
| 淘汰賽 | 前八名，八強及四強單局，冠軍三戰兩勝；每局重新骰子猜先 |
| 特別桌 | 主辦指定隊伍獨立對戰，不計瑞士排名或淘汰晉級 |

下一輪需等本輪全部結果完成；特別桌不阻擋正式輪次。比賽手數、隊伍紀錄與淘汰賽對決圖可供選手及觀眾查看。

## 當日操作

1. 賽前核對 18 隊與固定碼卡，確認 AI、主機 IP、50 台實機連線及備援。不需逐隊勾選資格或檢錄。
2. 公告規則、時計、猜先與雙虛手按現況計分，儲存規則確認。
3. 建立瑞士輪、一鍵開始本輪，提醒選手在準備前設定自備設備，再骰子選色及雙方準備。
4. 全部結果完成後核對排名、備份，再建立下一輪，共五輪。
5. 五輪後建立八強、四強、冠軍戰；冠軍依三戰兩勝決定後續場次。
6. 結束後備份、匯出與核對發放資料。出場費、積分及獎金由主辦實際發放，程式不代付。

## 異常與備援

裁判可個別或全場暫停，排除後恢復；暫停與重賽填原因，裁定勝負不需理由。AI 失敗會暫停受影響棋局，不使用假勝率。主機重啟保留正式棋局及時計，忽略停機時間，先暫停等待核對。

每輪複製 data/backups 的完整備份到另一台主機或 USB。JSON 匯出供核對，不是完整還原檔。還原先停止服務並保留現有資料，再把已驗證的備份放到新資料目錄的 tournament.sqlite3，使用原引擎路徑啟動；新目錄會產生管理金鑰。不要在服務執行時只複製主資料庫而忽略 WAL。

單機練習使用同一網址與 AI，僅同一裝置人對人／人對電腦，不能跨裝置加入。每個瀏覽器只保留一桌；收桌、閒置或重啟會清除，請先下載 SGF。
