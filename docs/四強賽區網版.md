# 區域網路四強賽（Windows 10／11 x64）

下載 **yanghai-windows-final-four-lan-port8080**。完整解壓附件與內層 ZIP，保留整個資料夾。只在主辦主機雙擊 **Start-FinalFour-LAN-8080.cmd**，選手電腦使用瀏覽器。

## 主辦設定

1. 主機與選手電腦連到相同區域網路。Windows 防火牆提示時，允許本程式使用私人網路。
2. 啟動後會開啟主辦頁 `http://127.0.0.1:8080/#admin`。以記事本開啟程式資料夾內的 **final-four-lan-data/admin-token**，將管理金鑰輸入主辦頁登入。
3. 已內建原本的 **18 隊隊名、隊員與固定點棋碼**。在四個下拉選單選出本次參賽的四隊，按「建立四強對決圖」。第 1 隊對第 2 隊，第 3 隊對第 4 隊。
4. 分別開啟兩場四強，兩桌可以同時進行。四強一戰決勝；兩場勝隊自動進入冠軍戰，冠軍戰三戰兩勝。先贏兩局即結束，1：1 時才開第三局。
5. 在「區域網路開賽」複製參賽網址，例如 **http://192.168.1.100:8080/#arena**，交給各隊。主機程式視窗保持開啟。

主辦可在後台暫停、恢復、裁定及查看棋局；選隊、開桌與裁定均須管理金鑰。主辦從後台或隨附 **TEAM-CODES.html／TEAM-CODES.csv** 查看、列印原本的固定點棋碼，再分發給各隊。新安裝使用相同固定碼，不需重新制發。

## 選手操作

1. 在自己的電腦開啟主辦提供的區網網址，進入本隊對戰桌。
2. 下拉選擇自己的隊伍，輸入本隊點棋碼後入座。點棋碼由伺服器驗證；其他隊的碼無法操作這張桌。觀戰不需登入。
3. 雙方各擲兩顆骰子並確認，較高者選黑或白，同點重擲。各按「準備好了」後開始。

四強與冠軍戰每局每隊皆為 **10 分鐘**；攜帶電子產品者 **5 分鐘**。AI 分析與排隊時暫停計時。預設 19 路、黑貼 7.5 目、中國規則及 128 visits。禁止 AI 最佳落點，從第 61 手起連續三個自身回合勝率 ≤ 40% 判負；雙方連續虛手按棋盤現況及貼目計分，不另移除死子。

## 資料與重啟

使用獨立的 **final-four-lan.json** 與 **final-four-lan-data/**，不讀取原單機版或原瑞士賽資料。重啟保留名單、固定碼、對決圖與棋局；進行中的棋局會暫停，由主辦確認後恢復。每局可下載 SGF，主辦可備份或匯出整屆紀錄。

程式監聽 **0.0.0.0:8080**，CMD 與新設定檔明確使用 8080。主辦可於自身主機使用 127.0.0.1；選手使用主機的區域網路 IPv4。隨附 CPU 與 NVIDIA GPU 引擎，預設自動選擇，GPU 不可用時使用 CPU。隨附模型與分析預算仍應由主辦在活動前用實際設備彩排驗收。
