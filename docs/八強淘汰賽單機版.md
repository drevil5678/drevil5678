# 八強淘汰賽單機版（Windows 10／11 x64）

下載 **yanghai-windows-knockout-v0.8.1**，完整解壓附件與其中的 ZIP，保留整個資料夾。雙擊 **YanghaiKnockout.exe**，或 **Start-Knockout-Offline.cmd**，會自動開啟本機瀏覽器。不需安裝 Python、不需網路，也不需要管理金鑰或點棋碼。支援 AVX2 的 x64 CPU 即可使用隨附 CPU KataGo；不需 NVIDIA 顯示卡。

若未自動開啟，請在同一台電腦輸入 `http://127.0.0.1:8001`。本版一次只進行一局，兩隊輪流操作同一個棋盤。

1. 輸入八個不同隊名，並核對棋盤、貼目與規則。預設 19 路、黑貼 7.5 目、中國規則、128 visits；如活動另有指定，請先改成一致。
2. 輸入順序即八強配對：第 1 隊對第 2 隊、第 3 隊對第 4 隊、第 5 隊對第 6 隊、第 7 隊對第 8 隊。八強第 1／2 組勝隊進四強第 1 組，第 3／4 組勝隊進四強第 2 組。
3. 確認後按「建立八強對決圖」。隊名與規則鎖定；本版不需先打瑞士賽。
4. 在賽場選擇要進行的組別。每局開始前勾選該隊是否攜帶電子產品，再按「開啟第 N 局」。
5. 每局雙方重新擲兩顆骰子、按確定，由高點數者選棋色，再由雙方各按準備。操作席隨目前回合自動切換，不需輸入點棋碼。
6. 八強、四強一局定勝負；**只有冠軍戰採三戰兩勝**，先贏兩局者奪冠。1：1 時需開第三局，2：0 時不能再開第三局。每局勝利只算一勝，40% 判負的 1.25 分不會算成 1.25 勝。
7. 賽果自動累計，勝隊自動帶入下一階段；主辦選擇下一局開啟。上方「淘汰賽對決圖」可查看各組勝局數與冠軍。

八強、四強每局每隊 **10 分鐘**，攜帶電子產品者 **5 分鐘**；冠軍戰每局 **15 分鐘**，攜帶電子產品者 **10 分鐘**。共用的比賽電腦不算額外自備設備。分析與排隊時暫停計時。

沿用禁止 AI 最佳落點、從第 61 手起連續三個自身回合最佳合法可選點勝率 ≤ 40% 判負，以及雙方連續虛手按棋盤現況與貼目計分等規則。主辦可暫停、恢復或裁定單局勝隊，不會覆寫已完成結果。平手需由主辦裁定，不自動算任何一方一勝。

本版使用獨立的 **knockout.json** 與 **knockout-data/**，不讀取原本的 `data/` 或 `duel-data/`。重啟會保留八隊名單、配對、勝局與棋盤；未完成對弈以暫停狀態恢復，請點該組「回到第 N 局」，由主辦恢復。

每局可下載 SGF；賽場可下載整屆 JSON 紀錄。先備份整個資料夾再搬移。若要舉辦另一屆，將乾淨套件解壓到新的資料夾，勿刪除現有紀錄。此版的賽果不自動回寫原本瑞士賽網站；隨附模型與原備用版相同，其正式比賽棋力仍需主辦評估。

從 v0.8.0 升級時，尚未開賽的四強改為一局定勝負；已開賽的四強對戰保留原三戰兩勝與既有紀錄，避免更換晉級隊伍。新建立的賽事全部適用「只有冠軍戰三戰兩勝」。
