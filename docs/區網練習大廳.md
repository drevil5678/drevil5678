# 同一網站的單機練習（v0.7.1）

雙擊 **Start-LAN.cmd** 啟動主網站；選手使用原本參賽網址，在賽場、積分榜、隊伍紀錄同列的「練習」進入。練習與正式網站使用相同連接埠，預設 8000，不需另外啟動 8001。

## 對弈方式

- **同機雙人**：兩位玩家共用一台電腦，輪流執黑白。
- **與電腦對戰**：一人選擇黑／白，由主機 AI 自動回應。

練習預設關閉。主辦登入後，在「練習開放控制」按「開啟練習」，選手再用既有隊伍點棋碼登入。點棋碼由後端驗證，不會把有效碼名單交給練習頁面；登入憑證以 HttpOnly Cookie 保存，綁定原瀏覽器與裝置。未登入無法直接呼叫 API 開桌或操作棋局。

不提供跨電腦真人對戰、公開邀請入座或另一台電腦加入棋局。每桌綁定開桌瀏覽器與裝置，請在原瀏覽器繼續。收桌後才能登出或切換隊伍。

主辦可隨時「關閉練習」，停止落子、悔棋與電腦回應，保留棋盤供原瀏覽器下載 SGF 或收桌；重新開放後可繼續。暫停中的棋局不計閒置時間。開關會保存至下次啟動；練習棋局與登入本身在主機重啟後清除，選手須重新登入。

## 桌數與保存

每個瀏覽器只保留一桌，包含分析中、對弈中及已結束尚未收桌的棋局。重新整理或另開分頁會回到原桌；想換對戰方式請先下載 SGF、收桌，再開新局。閒置 30 分鐘自動回收。練習不計正式成績、無計時、不啟用連續低勝率判負。棋盤、貼目及禁止 AI 首選可調整。

重新整理可繼續。棋局保存在主機記憶體，收桌、逾時或重啟會清除；請先下載 SGF。練習與正式賽共用主機 AI，實際分析等待時間應以正式硬體及同時負載彩排。

## 舊啟動器

`Start-Practice.cmd`／`Start-Practice-LAN.cmd` 及 `--practice-lan` 改為主網站的相容入口，不再開放舊版跨裝置真人桌。`Start-Practice-Offline.cmd`／`--practice` 保留僅限本機的舊雙人練習模式；一般活動直接使用 Start-LAN 即可。
